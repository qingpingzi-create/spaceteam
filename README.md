# 太空小队 · 反应力挑战

无需安装依赖、无需登录的中文网页互动游戏。直接双击 `打开游戏.cmd` 或打开 `dist/index.html` 即可离线使用。所有资源均随项目提供，无需外部字体或图片。

## 游戏

- 操作方式：空格键、鼠标、触屏。整轮只接受选择的操作方式，记录也按操作方式分别比较。
- 练习：3 次发射 + 5 次保护飞船；不评分、不存入记录。
- 正式：10 次发射 + 20 次保护飞船（14 个陨石、6 艘友军，顺序随机）。
- 信号前等待 1～2.5 秒；第一关响应窗口 1.8 秒，第二关 1.4 秒。
- 信号前操作算抢跑；信号后小于 100 ms 算预判；友军时操作算误点；目标超时算漏答。
- 暂停、切换标签页、窗口失焦时停止计时。已完成题目保留，未完成题目在继续后重新出题。
- 反馈音默认关闭，目标出现时不播放提示音。
- 本机最近 50 次正式成绩；可导出含每题记录的 UTF-8 CSV，Excel 可打开。

## 计分

设 A 为全部题目正确率（0～1），M 为有效反应时间中位数，D 为有效反应时间中位绝对偏差。

- 速度：50 × clamp((900 - M) / 650, 0, 1) × A；没有有效反应为 0。
- 准确性：35 × A。
- 稳定性：15 × clamp(1 - D / 250, 0, 1) × A；有效反应不足 3 次为 0。
- 总分为三项未取整分数相加后四舍五入。分项显示保留一位小数。

阈值为当前游戏规则，未经年级常模校准，不应解释为科学测定或年龄排名。设备和输入延迟会影响绝对反应时间；优先在同设备、同操作方式下比较个人变化。

## 预览与验证

安装了 Node.js 时：`node serve.cjs`，访问 http://127.0.0.1:4173。

验证评分：`node verify.cjs`。验证完整流程：`node verify-flow.cjs`（虚拟 DOM 与时钟，覆盖完整挑战、练习、暂停、键盘与触屏逻辑及存储不可用情况）。

项目采用原生 HTML/CSS/JavaScript，不包含第三方依赖。部署目录为 `dist`。
